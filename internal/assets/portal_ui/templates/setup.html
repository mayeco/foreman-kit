{{iconc "refresh-cw" "size-4 text-primary"}}Bring the repositories up to date

The main checkout and each child repository are brought up to date with origin, as foreman-kit sync does: a branch that can be fast-forwarded is, and one that diverged is said and left as it is. Publishing also pushes the commits a child repository has and origin does not, and then commits and pushes their pointers in the main checkout; it is refused while a dispatcher or a merger runs. Neither is done while a visual QA session is in progress: the main checkout is left as it is until the session ends.

{{iconc "folder-git-2" "size-4 text-primary"}}Add or prepare a child repository

Lowercase letters, digits, dots, underscores and hyphens, starting with a letter or a digit.

With a URL the repository is added under repos/ and prepared. With a name alone, the repository of that name is prepared: it gets its repo.config.yaml.
